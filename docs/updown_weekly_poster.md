# 加密货币 Up/Down 周统计海报

周报使用已确认的酒红、香槟金背景，字体和图表由程序按真实统计精确绘制，输出 1600 × 2000 的不透明 PNG、配套统计 JSON 和英文推文正文。

```bash
.venv-btc5m/bin/python scripts/polymarket_updown_weekly_poster.py --week-start 2026-09-14
```

指定 UTC 周一，统计连续七个市场结束日。上述命令覆盖 2026-09-14 至 2026-09-20，与 2026-09-07 至 2026-09-13 比较。可通过 `--db` 和 `--output-dir` 指定本地数据库与输出目录。

省略 `--week-start` 时，脚本启动时根据当前 UTC 日期确定上一个完整周的周一，日期在本次运行中固定。可直接运行：

```bash
.venv-btc5m/bin/python scripts/polymarket_updown_weekly_poster.py
```

本机定时任务 `polymarket-updown-weekly.timer` 每周一 11:30（Asia/Tokyo）启动对应服务，运行上述默认入口，生成上周海报、JSON 和推文。使用本地已采集的数据，缺口沿用现有退出语义；运行日志可通过 `journalctl --user -u polymarket-updown-weekly.service` 查看。电脑关闭期间错过的时点不补跑，之后在下一个周一按计划执行。

默认生成原总览 `updown_weekly_2026-09-14_2026-09-20.png`、同名 JSON 和 `_tweet.md`，以及 `updown_buy_trade_distribution_all_series_weekly_2026-09-14_2026-09-20.png`、同名分布 JSON、中文正文、六张抖音卡片和发布清单。总览 JSON 保存分布资产的周期引用与 SHA256。
总览与比较期使用同一只读事务；关闭后，分布使用独立只读短查询。目标周缺口或重建校验失败返回2。前周缺失时总览环比显示 N/A，不妨碍完整目标周的分布生成。

新版推文使用同批汇总和分布数据，包含完整周与 UTC、原市场成交额、去重钱包数、两组重建 BUY 事件的 Trades、Shares 和 Up 等价金额。机器人比例明确为 Up 等价金额加权的买方参与覆盖率。市场额与事件金额分别表达；总览保留市场与钱包数环比，机器人模块直接复用分布汇总。

模板限280个 ASCII 字符（含换行），长数字采用两位小数的 K/M/B/T 紧凑格式，精确值在 JSON 和分布表中。无法完整表达时拒绝生成，不截断单位或分母。`--without-distribution` 保留原总览、旧推文与旧四张中文卡片；`--with-distribution` 可显式启用默认新版。

`_tweet.md` 仅含可发布的英文正文和换行。新版英文平台按清单依次使用总览和分布两图；抖音按清单依次使用六卡：总览、趋势、高频地址解释、全部 BUY 分布、机器人 BUY 分布、方法。见[发布规则](updown_publishing.md)。

## 内容与口径

内容依次为周市场成交额及周环比、周去重钱包数及周环比、七天成交额柱状图、币种成交额占比、疑似机器人活动和口径说明，不加入一句话观察。

- 市场范围沿用现有 38 个系列目录；日期按市场结束日归属，包含所选市场全部提前及跨日成交。
- 市场金额只计吃单方一次，使用整数微 USDC。机器人金额和钱包金额分母只累计 BUY；机器人判定特征继续沿用原 BUY＋SELL 活动记录，不因金额筛选而改变。百分比由未舍入值计算。
- 周钱包数对整周钱包取并集，不相加每日钱包数。
- 疑似机器人与日报、月报共用 `first_hit_day_onward` 标签。系统从现库最早相关市场结束日开始，逐日跨系列合并同一钱包全部 BUY＋SELL 记录；记录数大于1、平均成交间隔不超过60秒、跨度至少90分钟时首次命中。
- 首次命中当日及以后持续归为疑似机器人；后续低频日也纳入，但首次命中之前的成交不使用未来标签回算。周钱包数取本周实际出现、且在对应日已经命中的钱包并集；金额汇总这些钱包生效日及之后的当日记录。
- 首次命中表示现库首次观察证据。历史缺失或未采完整日期不能证明真实首次操作日；共享名单来源与不完整历史信息保留在分布 JSON 的 `bot_history` 中。
- 默认机器人模块与分布页共用重建 BUY 事件汇总及 Up 等价金额，比例为买方参与覆盖率，分母为全部本周 BUY 事件的 Up 等价金额。无同口径前期分布时，机器人覆盖率环比显示 N/A，不拿原钱包金额比例比较。无分布模式只采用钱包自身原价 BUY 金额及对应全钱包 BUY 分母。
- 币种图展示本周成交额前三名及其余币种合计。`solana` 归入 SOL，`dogecoin` 归入 DOGE。完整币种金额保存在 JSON。
- 柱状图从零起算，柱高和占比条宽度按未舍入金额绘制，标签保留两位小数。
- 前期零基数、前期缺失、零钱包成交额分母沿用日海报 N/A 语义。
- 任何日期缺少单边金额时，周总额及币种占比显示 N/A；每日图标记缺失日期，不以零代替。比较期缺少单边金额时仅市场成交额环比缺失，钱包和机器人对比独立计算。

背景为 `assets/posters/updown_weekly_background_v1.png`；周、月共用的查询见 `sql/updown_period.sql`。
聚合按日处理钱包特征，跨日仅保留钱包并集与金额汇总。历史系列启用边界沿用[每日覆盖定义](updown_daily.md)。
正式版不调用图像生成模型绘制文字或数据图表。

## 买入交易分布

原周总览继续保留七日趋势、币种构成等内容。分布已接入原周报默认入口。仅需单独生成分布页时：

```bash
.venv-btc5m/bin/python scripts/polymarket_updown_bot_price_poster.py \
  --week-start 2026-11-02 \
  --output-dir outputs/previews/weekly_buy_distribution_2026-11-02_2026-11-08_v1
```

生成酒红与香槟金风格的
`updown_buy_trade_distribution_all_series_weekly_2026-11-02_2026-11-08.png` 和同名 JSON。
全部钱包与疑似机器人两图均只统计 BUY 参与的重建成交，展示 Trades、Trade %、Shares、
Notional (USDC)、Notional %，不加入 NOTIONAL MIX。

逐日复用[与日报相同的成交重建和镜像去重方法](updown_bot_price_poster.md)，每条对手明细形成一笔成交，
汇总行不另计。整周先合并未舍入原值，再计算比例；Trade % 以本图周总笔数为分母，
两图的 Notional % 均以全部钱包本周 BUY 名义金额为分母。名义金额为 Up 等价价格乘 Shares，
与原总览吃单方市场成交额不同。任何目标日缺失、重建不通过或源数据变化均拒绝导出完整周分布。
整套周报先在暂存目录生成并校验，全部成功后写入最终目录，发布清单最后更新。预览使用独立输出目录，以保留已发布历史版本。
