# 加密货币 Up/Down 周统计海报

周报使用已确认的酒红、香槟金背景，字体和图表由程序按真实统计精确绘制，输出 1600 × 2000 的不透明 PNG、配套统计 JSON 和英文推文正文。

```bash
.venv-btc5m/bin/python scripts/polymarket_updown_weekly_poster.py --week-start 2026-09-14
```

指定 UTC 周一，统计连续七个市场结束日。上述命令覆盖 2026-09-14 至 2026-09-20，与 2026-09-07 至 2026-09-13 比较。可通过 `--db` 和 `--output-dir` 指定本地数据库与输出目录。

省略 `--week-start` 时，脚本启动时根据当前 UTC 日期确定上一个完整周的周一，日期在本次运行中固定。可直接运行：

```bash
.venv-btc5m/bin/python scripts/polymarket_updown_weekly_poster.py
```

本机定时任务 `polymarket-updown-weekly.timer` 每周一 11:30（Asia/Tokyo）启动对应服务，运行上述默认入口，生成上周海报、JSON 和推文。使用本地已采集的数据，缺口沿用现有退出语义；运行日志可通过 `journalctl --user -u polymarket-updown-weekly.service` 查看。电脑关闭期间错过的时点不补跑，之后在下一个周一按计划执行。

输出文件为 `outputs/posters/updown_weekly_2026-09-14_2026-09-20.png`、同名 `.json` 和 `updown_weekly_2026-09-14_2026-09-20_tweet.md`。数据查询使用同一个只读事务，不联网、不启动采集；当前周中的各日沿用日报完整性要求，存在缺口时返回退出码 2，不生成海报及推文。前周缺失时环比显示 N/A。

推文与海报使用同一次查询的汇总结果，包含完整周日期范围、周成交额及环比、周去重钱包数及环比、疑似机器人钱包数与成交额占比。机器人成交额占比的百分点变化及详细口径保留在海报中。成交额达到一百万 USDC 时显示两位小数的 M 单位，否则显示完整金额。前周缺失、零基数或零成交额分母显示 N/A 并用简短文字说明原因。

模板按 X 普通推文的 280 个加权字符限制设计，仅使用 ASCII 字符且不含链接，字符数包含换行。若较长的数字使标准模板超限，则省略正文中的机器人钱包数，将口径提示压缩为参见配图，保留成交额、去重钱包数及其周环比和疑似机器人占比。长度测试覆盖真实周报、缺失前周、零基数和大数值。规则依据：[X 发布说明](https://help.x.com/en/using-x/how-to-post)及[官方字符权重配置](https://github.com/twitter/twitter-text/blob/master/config/v3.json)。

`_tweet.md` 仅含可直接发布的英文正文和换行，不带 Markdown 标题、代码围栏或操作说明，也不加入一句话观察。发布时将该文件全文与同名 PNG 配套使用。

## 内容与口径

内容依次为周钱包成交额及周环比、周去重钱包数及周环比、七天成交额柱状图、币种成交额占比、疑似机器人活动和口径说明，不加入一句话观察。

- 市场范围沿用现有 38 个系列目录；日期按市场结束日归属，包含所选市场全部提前及跨日成交。
- 金额沿用整数微 USDC，买入支出加卖出收入。百分比由未舍入整数金额计算。
- 周钱包数对整周钱包取并集，不相加每日钱包数。
- 机器人先跨系列合并同一钱包同一统计日的记录，再沿用日海报筛选条件：平均成交间隔不超过 60 秒、首末成交跨度至少 90 分钟。
- 疑似机器人钱包数为每日被标记钱包的周内并集；金额仅累加被标记的钱包在对应日市场中的成交额，不把该钱包其他未标记日的金额一并纳入。
- 机器人周占比以周总金额为分母，占比的周变化用百分点表达。此为行为筛选，不确认身份。
- 币种图展示本周成交额前三名及其余币种合计。`solana` 归入 SOL，`dogecoin` 归入 DOGE。完整币种金额保存在 JSON。
- 柱状图从零起算，柱高和占比条宽度按未舍入金额绘制，标签保留两位小数。
- 前期零基数、前期缺失、零成交额分母沿用日海报 N/A 语义。

背景为 `assets/posters/updown_weekly_background_v1.png`；查询见 `sql/updown_weekly_poster.sql`。正式版不调用图像生成模型绘制文字或数据图表。
